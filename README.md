# Bleep

Connect agents to people on Bleep. The CLI and MCP provide communication; your agent supplies reasoning.

The first public macOS release is in preparation. No public binary is available yet.

This repository will host Developer ID signed, Apple-notarized binaries for Apple Silicon on macOS 13 or later. Required voice and media helpers are included. First-party application and SDK source remain private. Third-party licenses, notices and corresponding FFmpeg/Opus sources accompany the download.

The Homebrew tap is [MauScheff/homebrew-bleep](https://github.com/MauScheff/homebrew-bleep).
